# 🗓️ Professor Class Schedule Generator

A clean, professional web application for professors to create and manage their weekly class schedules. Built with Streamlit and designed for easy semester-to-semester updates.

## ✨ Features

- **📅 Visual Weekly Schedule**: Clean, professional grid layout
- **🎨 Color-Coded Classes**: Assign unique colors to different courses
- **🏢 Office Hours Integration**: Add and display office hours
- **📱 Mobile Friendly**: Responsive design works on all devices
- **💾 Export Options**: Print-friendly and screenshot-ready
- **🔄 Easy Updates**: Modify schedule each semester with simple forms
- **⚠️ Conflict Detection**: Prevents double-booking time slots

## 🕒 Pre-configured Time Periods

The app uses standard university time slots:
- **Period 1**: 9:00-10:30
- **Period 2**: 10:45-12:15
- **Lunch Break**: 12:15-13:10
- **Period 3**: 13:10-14:40
- **Period 4**: 14:55-16:25
- **Period 5**: 16:40-18:10

## 📖 How to Use

### 1. Enter Semester Info
- Add semester (e.g., "Fall 2024")
- Enter your name

### 2. Add Classes
- Course name (e.g., "CS 101 - Intro to Programming")
- Select day and period
- Enter classroom/location
- Choose a color for visual coding

### 3. Add Office Hours
- Select day and time range
- Enter office location

### 4. View & Export
- **Visual Schedule**: See your professional weekly grid
- **Class List**: Review all classes and office hours
- **Export**: Print to PDF or take screenshots

## 🔧 Technical Features

- **Conflict Detection**: Prevents scheduling conflicts
- **Data Persistence**: Your schedule persists during session
- **Backup & Restore**: Download your data as JSON
- **Responsive Design**: Works on desktop, tablet, mobile
- **Print Optimized**: Clean output for printing
